## `04` / How I Think About AI Systems

```text
User request
    ↓
Application / API
    ↓
Context + data retrieval ──→ Relevant knowledge
    ↓
LLM + tools
    ↓
Structured result
    ↓
Validation + business rules
    ↓
Useful, observable application output
```

My guiding principles:

- **Build systems, not just demos.** An AI feature needs a clear purpose and a usable interface.
- **Ground answers in context.** Retrieve relevant information when the task depends on private or domain-specific data.
- **Validate critical outputs.** Treat model responses as inputs that may need schema checks and business rules.
- **Keep responsibilities clear.** Let models handle language and flexible reasoning; let deterministic code handle rules that must be consistent.
- **Design for failure.** Consider timeouts, missing data, retries, logging, and human review where appropriate.
